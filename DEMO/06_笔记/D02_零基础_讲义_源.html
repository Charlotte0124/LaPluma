0本讲导读Read Me First

这一节能解决什么。让你在读原文之前知道它在讲什么事、为什么值得读——先有骨架，再抠字词，最后才谈主题。

这一节不能解决什么。不替你背文学史年代（记不住不影响读懂本文），也不给「标准答案式」的中心思想（central theme），只给判断依据。

读法把本文当成一个叙事来读：谁进了哪里、看到了什么、后来又怎样。三段都发生在「桃花源（Peach Blossom Spring）」里，第四段回到「找不到」，落点就在这个「找不到」上。

本讲引用的页码都指原始课件（4 页版），你在纸面上能一页一页对回去，这就是「可核对」。

1陶渊明与这篇文章的位置Author and Setting

讲法。先说清作者与时代，再谈文章。依据是《宋书·隐逸传》与本文小序的说法（课件 p.1）：他做官做得不开心，辞了回乡下，写的东西多半跟田园、跟「另一种活法」有关。

陶渊明（约 365—427），东晋末年到南朝宋初的人。他做过几任小官，最后一任是彭泽县令，只做了八十多天就辞了，理由写在《归去来兮辞》序里：不想为了五斗米向乡里小儿折腰。这不是清高姿态，是算过账的选择——当时的官场要站队、要应酬，他受不了。

《桃花源（Peach Blossom Spring）记》常被认为写于他归隐之后。它不是凭空想出来的：战乱、赋役、人口流亡是那个时代的日常，所以他笔下那个「不知有汉，无论魏晋」的地方，本质是把现实倒过来写——外面越乱，里面越安稳。

晋太元中，武陵人捕鱼为业。缘溪行，忘路之远近。 课件 p.2 · 开篇一句，时代与主人公都在里面
开篇写「晋太元中」，为什么把一个模糊的年号写清楚，却把主人公写成「捕鱼为业」的无名者？
  1. 年号给的是可信的坐标：让读者以为这是真事，后面「不复得路」才有分量（课件 p.4）
  2. 不给姓名给职业，是因为他要的不是一个人，而是一类人——普通、无特权、随时可能被时代碾过去的那类
  3. 两件事合起来：用真实的外壳，装一个不可能的梦
答案：真年号 + 无名者 = 可信的外壳。这一点决定后文为什么必须写「不复得路」，见 §6。

2四段骨架与三条线索Four Movements, Three Threads

讲法。先把叙事顺序（narrative order）画出来，再谈细节。四段的段落大意（paragraph gist）我用一句话概括（课件 p.4），你读完可以自己改——改得动，说明你真读懂了；改不动，说明还在背。

四段的段落大意我一句话一段，表在下面（课件 p.4）；表后的三条线索（narrative thread）用来把它们串起来（课件 p.2）。

段段落大意（一句话）在文章里的作用
一渔人缘溪误入桃花林，穿过山口，见到村子进入：把读者带进去
二村里人请他回家，说祖上避乱而来，不知外面的朝代展开：交代这个地方为什么存在
三渔人出来后沿路做记号，太守派人去找，找不到转折：记号失效，入口消失
四刘子骥想去，没去成，此后无人问津收束：把「找不到」钉死

三条线索贯穿全篇：一是空间线索，从溪到林到山到洞口到村，一路「越来越窄」，最后「豁然开朗」；二是人物对话（dialogue），全靠问答交代背景，作者一次也没站出来解说；三是记号，处处志之是全文唯一一次「人想留住什么」，结果恰好在这一处失效。

环境描写（setting）不是闲笔：桃花林写「芳草鲜美，落英缤纷」，进村写「土地平旷，屋舍俨然」，一外一内，先美后安，读者的安全感是被这两笔铺出来的。

如果把第三段「处处志之」删掉，故事还能讲完吗？
  1. 能讲完，但会变成「偶然走丢」的奇闻，而不是「有人想回去、回不去」的悲剧
  2. 记号是全文唯一一次主动挽留；它失效，才说明桃花源（Peach Blossom Spring）不接受被安排
  3. 所以这一笔不是道具，是主题的一半
答案：删得掉，代价是把主题删掉了。判断依据：第四段「不复得路」靠的正是记号的失效。

3十二个字词：通假、古今异义、一词多义Twelve Words That Trip You Up

讲法。文言文（Classical Chinese）读不懂，九成不是语法问题，是字词。这一节只做一件事：把最容易按今义理解的十二个词挑出来，一个词给三样——句中义、今天的意思、凭什么这样判（课件 p.3）。

先立三条判断依据，后面每个词都能套（课件 p.3）：①看搭配，「率妻子邑人」里「妻子」后面跟「邑人」，说明它跟人并列，只能是「妻子和儿女」；②看上下文，「绝境」前有「来此」，后有「不复出焉」，只能是「与世隔绝的地方」；③看句式，「渔人甚异之」里「异」带了宾语，只能是动词或意动用法（putative usage）。

下面这张表是 §3 的整理，一栏是句中义，一栏是今天的意思（课件 p.3）：

词句中义（本文）今天的意思 / 辨析
妻子妻子和儿女今只指男子的配偶（古今异义（semantic shift））
绝境与世隔绝的地方今多指走投无路的处境（古今异义）
无论不要说、更不必说今是连词「不管」（古今异义）
交通交错相通今指运输事业（古今异义）
鲜美鲜艳美丽今多形容味道好（古今异义）
俨然整齐的样子今多指「好像、宛然」
寻随即、不久（寻病终）今是「寻找」（一词多义（polysemy））
志做记号（处处志之）/ 标记（寻向所志）同字两义，一动词一名词
要同「邀」，邀请（通假字（phonetic loan character））今为「需要、重要」
具同「俱」，全、都（通假字）今为「具备、工具」
异认为……奇怪（意动用法）今为「不同、奇异」
穷走到尽头（欲穷其林）今多指「贫穷」
「率妻子邑人来此绝境，不复出焉」该怎么译？请先指出两个易错词，再给整句译文。
  1. 易错词一：妻子——是「妻子和儿女」，不是配偶一人（依据：与「邑人」并列，课件 p.3）
  2. 易错词二：绝境——是「与世隔绝的地方」，不是「绝路」（依据：后句「不复出焉」）
  3. 整句：带着妻子儿女和同乡的人来到这个与世隔绝的地方，没有再出去过
答案：两个词都属古今异义；判断靠搭配与上下文，不靠猜。回看 §3 表第一、二行。

4四句最容易译错的句子Four Sentences, One Method

讲法。句子翻译（sentence translation）不考文采，考的是「逐字对上 + 语序调整 + 补出省略」。方法固定三步：先按词切分（断句（sentence segmentation）），再把每个词的句中义填进去，最后补主语、调语序（课件 p.3）。（句译见课件 p.3 的对照栏）

四句都出自课件 p.2 的原文，逐句译法见课件 p.3 的对照欄；每题先切分、再填义（课件 p.3）。

「问今是何世，乃不知有汉，无论魏晋。」
  1. 切分：问 / 今 / 是 / 何世 ‖ 乃 / 不知 / 有汉 ‖ 无论 / 魏晋
  2. 填义：是=这；乃=竟然；无论=不要说
  3. 成品：（他们）问现在是什么朝代，竟然不知道有过汉朝，更不必说魏晋了
答案：三处要点——「是」「乃」「无论」。少一处就扣一处，这是可数的。
「此人一一为具言所闻，皆叹惋。」
  1. 切分：此人 / 一一 / 为 / 具言 / 所闻 ‖ 皆 / 叹惋
  2. 补省略：为（之）具言——「之」指村里人，翻译时要补出来
  3. 成品：这个人为他们详细说了自己所听到的事，（听的人）都感叹惋惜
答案：难点是省略宾语与「具言」的「具」（详细）。
「既出，得其船，便扶向路，处处志之。」
  1. 切分：既 / 出 ‖ 得 / 其船 ‖ 便 / 扶 / 向路 ‖ 处处 / 志 / 之
  2. 填义：既=已经；扶=沿着；向=先前的；志=做记号
  3. 成品：（渔人）出来以后，找到他的船，就沿着先前的路（回去），处处做了记号
答案：四个词连起来才通——「扶向路」是「沿着来时的路」，不是「扶着路」。
「寻向所志，遂迷，不复得路。」
  1. 切分：寻 / 向 / 所志 ‖ 遂 / 迷 ‖ 不复 / 得路
  2. 填义：寻=寻找；向=先前；所志=做的记号（名词性）
  3. 成品：寻找先前做的记号，竟然迷失了方向，再也找不到（通往桃花源（Peach Blossom Spring）的）路
答案：注意「志」在这里是名词（记号），与上句的动词用法不同——这正是一词多义（polysemy）。

5写作手法：白描、虚实与留白How It Is Written

讲法。这一节讲他「怎么写的」。三样手法，每样都给你指一处原文当证据（课件 p.2、p.4），你不同意可以拿别的原文反驳——这就是文学分析该有的样子。

三样手法各有一处证据（课件 p.2、p.4），先给例子再给结论：

  • 白描（plain sketch）：不形容，只列名词与动作。「土地平旷，屋舍俨然，有良田美池桑竹之属」——一个形容词都没有，画面却全出来了。
  • 虚实结合（real-and-imagined）：年号、郡名、人名（刘子骥实有其人）都是实的，桃花源（Peach Blossom Spring）本身是虚的；实的外壳越硬，虚的部分越可信。
  • 留白（deliberate blank）：村里人「避秦时乱」之后几百年怎么过的，作者一个字没写；渔人出去后有没有人信他，也没写。空出来的地方，读者自己填。

还有一处常被忽略的详略（proportion of detail）：进村前的路写得极细（溪、林、山、口、光），出村后的寻找写得极简（志之、寻向所志、遂迷）。详的让人身临其境，略的让失败来得干脆——这是作者在控制节奏。

「芳草鲜美，落英缤纷」这八个字，改写成「桃花开得很美，花瓣落了一地」好不好？
  1. 不好在两点：一是变虚了，「鲜美」「缤纷」是直接给出的画面，改写后成了评价
  2. 二是失去了对仗与节奏，八个字两句，读起来像走路，改写后像说明文
  3. 结论：白描的力量来自具体与克制，不是来自华丽
答案：评价可以主观，理由要能指到字上。回看 §5 第一条。

6主题：为什么偏要「不复得路」Why the Road Is Lost

讲法。最后落到主题。我的判断：这篇文章的中心思想（central theme）不在「桃花源（Peach Blossom Spring）多好」，而在「回不去」。理由三条，都能从文本里指出来（课件 p.4）。

第一条：寄托（allegory）的方向是现实（课件 p.4）。陶渊明写的不是旅游见闻，是他那个时代缺什么——没有战乱、没有赋役、老少各得其所。这些恰恰是东晋末年最缺的东西。

第二条：记号失效是刻意的（课件 p.4）。渔人「处处志之」，太守「遣人随其往」，结果「遂迷」。如果作者想让读者相信桃花源存在，就该让他们找到；偏不，说明他要的不是「存在」，而是「不可复制」。

第三条：结尾把可能性关死（课件 p.4）。「南阳刘子骥，高尚士也，闻之，欣然规往。未果，寻病终。后遂无问津者。」——连最该找到的人也失败了，于是世上不再有人找。这就是世外桃源（hidden utopia）这个词后来为什么总带一点遗憾。

后遂无问津者。 课件 p.4 · 全文最后五个字，把门关上了
有人说：「既然回不去，那写它干什么？」用本文回答这个问题，要求指到具体句子。
  1. 写它不是为了让人去，是为了让人知道自己缺什么——依据：村中「黄发垂髫，并怡然自乐」（课件 p.4）
  2. 回不去正好保证它不会被糟蹋：一旦能去，就会有人去、有人征税、有人争——依据：太守「遣人随其往」（课件 p.4）
  3. 所以「不复得路」不是败笔，是保护措施：理想只有不可达时才是理想
答案：三条都要指句子。回看 §6 第二、三条与「后遂无问津者」。

7本讲小结Takeaways

讲法。收口用一张表，每条都配一个能自己验的动作——不许只留「我觉得」。

8自测Self-check

讲法。五题都不考背诵：给你一个判断任务，答案里写明回哪一节。

Q1. 「率妻子邑人来此绝境」中的「妻子」和「绝境」，分别是什么意思？判断依据是什么？
答：妻子 = 妻子和儿女；绝境 = 与世隔绝的地方。依据是搭配（与「邑人」并列）与上下文（「不复出焉」）。回看 §3。
Q2. 把「既出，得其船，便扶向路，处处志之」译成现代汉语，并指出「扶」的意思。
答：（渔人）出来以后，找到他的船，就沿着先前的路（回去），处处做了记号。「扶」= 沿着。回看 §4。
Q3. 本文用了哪三种手法？每种给一处原文当证据。
答：白描（土地平旷，屋舍俨然）／虚实结合（晋太元中 + 虚构村落）／留白（避秦之后几百年怎么过的没写）。回看 §5。
Q4. 为什么作者一定要写「不复得路」？给出两条从原文出发的理由。
答：记号失效说明理想不可复制；连刘子骥也「未果」，把可能性关死，保护了它不被现实消耗。回看 §6。
Q5. 「处处志之」与「寻向所志」的「志」，词性与意思有什么不同？
答：前者是动词「做记号」，后者是名词「做的记号」——一词多义。回看 §3 表第八行。

常见误解

  1. 以为「妻子」就是配偶：本文是「妻子和儿女」，写作时按今义用会扣分。
  2. 以为主题是「向往美好生活」就完事：还要说清「为什么必须回不去」，否则等于没答。
  3. 以为「寻病终」是「寻找病」：这里的「寻」是「不久」。
  4. 以为段落大意可以随便写：大意要能被原文指认，改得动是因为读懂了，不是因为写得漂亮。
