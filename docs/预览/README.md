## 怎么重拍 / 怎么加新稿

1. 样张是独立 HTML（不引仓库代码），宽度 1120，用 Edge 无头拍：
   `msedge --headless --disable-gpu --hide-scrollbars --window-size=1120,<高> --screenshot=<png> file:///<样张.html>`
2. 拍完**打开看一眼**：底部不能有半行被切，空白图（宽高与页面差 >2）算失败。
3. 新图必须在本表加一行（文件名 + 画的是什么 + 解决什么 + 状态）；不登记会被 `check-ui-preview.py` 判成孤儿图（红）。
4. 实现上线后，把状态改成「已实现」，并在 `../资产/` 补一张真实界面截图 `界面-<页>.png`。
