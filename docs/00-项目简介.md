# 羽毛笔 · 项目简介（置顶）

> 这一篇回答四件事：**它是什么、为什么做、现在能做什么、下一步做什么**。
> 最后核对：2026-11-22 ｜ 依据：`docs/00-总索引.md` 与 `功能总表.md`。

## 它是什么

把一讲的内容数据，渲染成一份能核对的讲义 PDF 的本地工具。

## 为什么做

老师备一讲：课件 → 讲义，格式与结构要能逐项核对。三道门（源 / 内容 / 版式）把「能不能用」判成红黄绿，不靠感觉。

## 现在能做什么

| 项 | 现状 |
|:--|:--|
| 讲义生成 | `python engine\_make.py D01`，一讲一条命令 |
| 合订本 | 界面「导出」选合订本，或 `python engine\_book.py` |
| 问课件 | 课程 → 卡片 → 抽屉底部「问这一门」，一个课件一个会话 |
| 质量门 | 源 / 内容 / 版式三道，任一红即停 |
| 界面 | 双击 `启动羽毛笔.cmd` 开原生窗口 |
| 导入 | PDF / 图片原生；Word / PPT / 文本 / Markdown 自动排成分页 PDF |

## 下一步

看 `功能总表.md` 里状态为「🟡 部分」「❌ 未实现」的条目；界面改动先出预览图再改码。

## 边界

1. AI 生成的内容可能不准，每份成品页脚都印「仅供参考」；
2. 脚本判不了对错，只查格式与结构，类比是否误导仍需人工抽查。
