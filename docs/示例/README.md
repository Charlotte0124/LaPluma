# 示例：桃花源记（范本 → 加工后）

> 这一目录只放**一份输入、一份输出**，用来让人一眼看出这个软件到底做了什么。
> 都属公有领域材料（陶渊明《桃花源记》），不含任何真实课程内容。

| 文件 | 它是什么 | 怎么来的 |
|:--|:--|:--|
| `桃花源记-范本.pdf` | **范本**：原始课件，4 页，白底、文字堆在一起、只有标题和要点 | 手工排的一份朴素课件（模拟"老师发给你的 PPT 导出"） |
| `桃花源记-讲义（加工后）.pdf` | **加工后**：13 页，深色讲义版式，分节 + 讲法 + 例题 + 术语表 + 自测 | `python engine\_make.py D02`（数据在 `DEMO\_lessons\D02.py`） |

## 差在哪（不是换皮）

| | 范本 | 加工后 |
|:--|:--|:--|
| 结构 | 4 页平铺要点 | 7 个概念节 + 小结 / 自测 / 术语表 / 附录，一节一页 |
| 讲法 | 只有结论 | 每节一段「讲法」说明凭什么这样判 |
| 可练 | 课后练习 3 条（无答案） | 每节带例题，题面 / 步骤 / 答案齐全；5 道自测题带「回看 §x」 |
| 术语 | 无 | 22 条术语表，每个术语**每节首次出现**附英文 |
| 可核对 | 无 | 每处引用标「课件 p.N」或 §节号，能回查到范本页 |
| 门 | 无 | 生成时过三道门：源 / 内容 / 版式，红了不出货 |

## 自己复现

```powershell
$env:PLUMA_COURSE='DEMO'
python engine\_make.py D02
```

产物落在 `DEMO\01_讲义\D02_桃花源记_讲义.pdf`；改 `DEMO\_lessons\D02.py` 里的任意一段，重跑，页数与内容都会跟着变——**讲义是数据渲染出来的，不是手写的**。
