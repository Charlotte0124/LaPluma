## 一、生成途径增加：链接 → 课程

用户原话：「加上增加生成途径 可以 通过连接（例如b站的链接 文档链接 论文连接等等）去生成课程」

- 入口不再只有「本地课件文件」：也可以给一条链接——B 站视频、文档页、论文页等。
- 要走通的话（按现有分层推）：链接先变成**可核对的源**（正文 / 字幕 / 图表 / 页码），
  再进现有的「骨架 → 补正文 → 三道门」，出处仍要能回指到源里的位置。
- 待定，不在这里替用户定：支持哪几类站点、B 站字幕与弹幕要不要、论文 PDF 怎么取、
  取不到时（付费墙 / 需要登录 / 纯视频无字幕）怎么照实说。
