# 快速开始

最后核对：2026-11-21 · 适用 v1.9.15

一句话：**下载仓库、装好 Python 3.12，双击 `启动羽毛笔.cmd` 就能用；不再提供单文件 exe。**

## 路一：文件夹版（推荐给只想用的）

1. 下载仓库压缩包（README 顶部「下载」按钮，或 `git clone`）。
2. 装 Python 3.12：<https://www.python.org/downloads/>，第一屏勾上 `Add python.exe to PATH`。
3. 双击目录里的 `启动羽毛笔.cmd`：先查 Python，再查 `pymupdf` 与 `pywebview`；**缺了会弹窗**——点「是」自动安装（要联网），点「否」打开下载页。
4. 首次启动出配置向导：选模型 → 填 API 钥匙（**可以跳过**）→ 选保存目录。
5. 自带示例课程 `DEMO`（2 讲），不配密钥也能出 PDF：点课程 → 点文件名 → 在软件里直接读。

课程、生成的 PDF、日志都写在**仓库目录**；配置在 `%USERPROFILE%\.pluma`。只有「问课件 / 让模型写内容 / 读余额」才需要密钥与联网。

## 路二：从源码跑

### 1. 装 Python 3.12

<https://www.python.org/downloads/> → 第一屏勾上 `Add python.exe to PATH` → `Install Now`。

验证（`cmd` 里）：

```
python --version
```

要看到 `Python 3.12.x`。

### 2. 拿代码

```powershell
git clone https://github.com/Charlotte0124/LaPluma.git
cd LaPluma
```

### 3. 双击 `启动羽毛笔.cmd`（或跑 `.\一键启动.ps1`）

`启动羽毛笔.cmd` 是无控制台入口：查 Python 版本（要 3.12，低了会拦下）→ 查 `pymupdf` → 查 `pywebview`（缺了弹窗安装）→ 起界面。
想看每一步的输出版本，直接跑 `.\一键启动.ps1`；只检查环境用 `.\一键启动.ps1 -CheckOnly`。
依赖装不上时，脚本会给出手动命令，图文版见 [07-装依赖-用CMD](07-装依赖-用CMD.md)。

### 4. 出第一份讲义（可选，验证流水线）

```powershell
$env:PLUMA_COURSE='DEMO'
python engine\_make.py D01
```

实测输出（v1.9.0，本机）：

```
生成 D01_零基础_讲义_源.html（16479 字符，术语附英 7 处，拆长段 0 处）
OK  DEMO/06_笔记/D01_零基础_讲义_源.html

1 份讲义源：OK 1 · WARN 0 · FAIL 0
已写    …\DEMO\01_讲义\D01_一份讲义是怎么出来的_讲义.pdf（1274 KB · 10 页 · 4722 字符）
WARN  D01_一份讲义是怎么出来的_讲义.pdf
      ! 页码引用偏少 1 处/10 页
  OK  D02_桃花源记_讲义.pdf
```

判定标准：**`1 份讲义源：OK 1 · WARN 0 · FAIL 0`、PDF 不是 0 页**。页数、KB 数随内容变，不是固定值。
末尾那条 `WARN` 是版的提示（顺带校验同门其它讲），不算失败。

> 不设 `PLUMA_COURSE` 时，默认课程取 `courses.json` 里**目录真实存在**的第一门；公开仓里只有 `DEMO`，你自己加了课程就按你的来。

## 出错对照

| 现象 | 怎么查 | 怎么改 |
|:--|:--|:--|
| 双击 `.cmd` 没反应 / 一闪就没 | 在 PowerShell 里跑 `.\一键启动.ps1 -CheckOnly` | 多半是没装 Python 3.12，见 [07-装依赖-用CMD](07-装依赖-用CMD.md) |
| 弹窗说缺 `pymupdf` / `pywebview` | 点「是」自动装；或 `python -c "import pymupdf, webview"` | `python -m pip install pymupdf pywebview`，见 07 |
| 打印报「找不到 Chrome」 | 系统里有没有 Chrome / Edge | 装一个，或用 `--chrome` 指定路径 |
| 内容门 `FAIL` 说缺 `data-reader` | 打开生成的源 HTML 搜 `data-reader` | 数据文件里补上读者口径 |
| 页面起首是正文（版式门红） | `python engine\_pagediag.py D01` 看逐页 | 在块边界插分页或补小标题 |
| 端口 8765 被占 | 是否又开了一个 | 软件会自动顺延到 8766–8774，看窗口里的提示 |
