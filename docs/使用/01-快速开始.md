# 快速开始

一句话：**装 Python 3.12、拉代码、跑一条命令，就有第一份 PDF；想看界面就再起一个网页。**

## 1. 准备（一次就够）

```powershell
python --version          # 需要 3.12
pip install pymupdf       # 打印后要数页、回填目录页码
```

还要有 **Chrome 或 Edge**（打印用它，不用装额外东西）。

## 2. 拿到代码

```powershell
git clone https://github.com/Charlotte0124/LaPluma.git
cd LaPluma
```

## 3. 生成第一份讲义

```powershell
python engine\_make.py L02
```

预期输出（照抄你自己的，判据在右边）：

```
生成 L02_零基础_讲义_源.html（30645 字符，术语附英 56 处，拆长段 0 处）
OK  CS340/06_笔记/L02_零基础_讲义_源.html
1 份讲义源：OK 1 · WARN 0 · FAIL 0
已写    …\CS340\01_讲义\L02_进程的基本管理_讲义.pdf（1622 KB · 18 页 · 13854 字符）
OK  L02_进程的基本管理_讲义.pdf
```

判定标准：**两处 `OK`、没有 `FAIL`、PDF 页数是 18**（数字随内容变，只要不是 0 页）。

## 4. 打开界面

```powershell
python ui\server.py
```

浏览器会自动打开 `http://127.0.0.1:8765/`。界面里能做的：点课程看成品、点文件名直接打开 PDF、选一讲生成、看生成日志。

只监听本机，不对外；Ctrl+C 停。

## 出错对照

| 现象 | 怎么查 | 怎么改 |
|:--|:--|:--|
| `ModuleNotFoundError: pymupdf` | `pip show pymupdf` | `pip install pymupdf` |
| 打印报「找不到 Chrome」 | 装了没装 Chrome/Edge | 装一个，或用 `--chrome` 指定路径 |
| 内容门 `FAIL` 说缺 `data-reader` | 打开生成的源 HTML 搜 `data-reader` | 数据文件里补上读者口径 |
| 页面起首是正文（版式门红） | `python engine\_pagediag.py L02` 看逐页 | 在块边界插分页或补小标题 |
