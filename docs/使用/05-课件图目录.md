# 课件图目录（引用课件原图时看这篇）

一句话：**讲义里的图分两种——自绘结构图（`svg`，不依赖外部文件）和课件原图（`fig`，只记文件名）。**
只有第二种需要这篇：图本身不在软件仓，得告诉它去哪找。

## 为什么会有这个问题

拆家之后，「按页裁的课件原图」留在资料仓（真实课程 共 1064 张、约 80 MB），软件仓里一张都没有。
`fig` 块只写文件名（例如 `L02_BasicProcessManagement_p011.jpg`），引擎按下面的顺序去找：

1. `%USERPROFILE%\.pluma\assets.json` 里该课程配的目录（**推荐**，本机文件、不入库存）
2. `courses.json` 里该课程的 `assets` 字段（会入库，只适合仓内相对路径）
3. 环境变量 `PLUMA_ASSETS`
4. 软件仓默认 `<课程>\06_笔记\assets`

**找不到就停。** 这一点是 2026-11-16 特意改的：以前图丢了 Chrome 只会画一个 14×16 的缺图图标，
成品里一条白条，而门只数「几张图」，于是报「6 图」绿灯——假绿。现在是缺图直接不打 PDF。

## 三条命令

```powershell
# 现在读哪个目录、有多少张图
python tools\assets.py --list

# 每讲引用的图能不能全部找到（缺就退 1，可以接进任何检查）
python tools\assets.py --check

# 指定课件图目录（写进 %USERPROFILE%\.pluma\assets.json，不入库）
python tools\assets.py --set <课程> "D:\你的课件\assets"
```

清掉本机配置：`python tools\assets.py --unset <课程>`。

## 三道门在这件事上各管什么

| 门 | 判据 | 红的样子 |
|:--|:--|:--|
| 引擎（`_make.py`） | `fig` 引用的文件找不到 | `缺图 6 张：…` + `[停]`，不打 PDF |
| 版式门 | 成品里每张图宽高都 ≥ 32px | `6 张图是破图（宽高 < 32px，Chrome 缺图图标）` |
| 内容门 | 不管图（只管 code/eg/讲法/术语） | — |

两条判据都要有：前者在生成前拦，后者在生成后拦（防止有人手改了 HTML 或漏配）。

## 打算怎么演进

L05–L09 已经把课件原图换成**自绘结构图**，不再依赖 `assets`；L02 / L03 / L04-01 返工时也会走这条路。
到时候 `assets` 只剩历史用途（旧 PDF 复现），`--check` 会全部显示「不引用图片（结构图自绘）」。
