# 问课件（在软件里直接追问，不用跑去外部 AI）

一句话：**选一讲 → 输一句问题 → 回答里带节号和课件页码，能当场翻回原页核对。**

它和「让聊天 AI 随便聊」的区别只有一条：**不许凭空答**。回答只能基于这一讲的内容数据，
片段是脚本按词命中挑出来的，模型只负责组织语言与标出处。

## 它是怎么工作的（三步，都能单独跑）

| 步 | 在哪 | 干什么 |
|:--|:--|:--|
| ① 切段 | `engine/_ask.py` 的 `fragments()` | 把一讲切成「节 + 块」级片段：讲法、段落、引文、代码、例题、图注、表格 |
| ② 检索 | `search()` | 问题切成 2–4 字滑窗 + 英文词，按命中次数打分，标题命中额外加权，取前 5 段 |
| ③ 回答 | `answer()` | 把片段（带 §节号、课件 p.N）拼成提问包交给模型；系统提示要求「先给结论 + 每句标出处 + 没写就说没写」 |

## 三条命令

```powershell
# 看这一讲被切成几段（不花钱）
python engine\_ask.py L05 --dump

# 只检索：看命中哪几段、提问包多大（不花钱）
python engine\_ask.py L05 "生产者消费者两行 down 的顺序为什么不能反"

# 真问（会花钱，走你配的 key）
python engine\_ask.py L05 "…" --ask
```

界面里走 `POST /api/ask`，与命令行同一套代码；界面会多给一块「命中的片段（核对用）」，
可以直接对照原文，判断它有没有编。

## 它不解决什么（先说清）

- **只在这一讲里找**，不跨讲、不联网、不读课件 PDF 原文（读的是讲义数据）。
- **找不到就会说「这讲里没写」**，但这靠提示词约束，脚本判不了它编没编——**得人看**。
- **不替代核对**：回答里的页码是片段自带的「课件 p.N」，仍要回原页确认。

## 花钱的边界

- 界面里点「提问」= 一次模型调用，进 `_logs\usage.jsonl` 台账，界面上「累计调用 / 估算花费」会跟着动。
- 没配 `sk-` 开头的钥匙时**不会扣费**：界面只显示命中的片段，并提示去设置里填。
