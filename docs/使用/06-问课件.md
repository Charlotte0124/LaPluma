# 问课件（一个课件一个会话）

一句话：**点开一门课 → 抽屉底部「问这一门 →」 → 这条会话只属于这门课，回答带节号与课件页码。**

它和「随便聊」的区别只有一条：**不许凭空答**。回答只能基于这门课的内容数据（默认整门课，也可以限定到某一讲），
片段是按词命中挑出来的，模型只负责组织语言与标出处。

## 一个课件一个会话（2026-11-16 定）

- **入口只有一处**：课程卡 → 右侧抽屉底部「问这一门 →」。（原来页面上那块「问课件」已经撤掉，一个动作只留一个入口。）
- **会话按课件分文件**：`%USERPROFILE%\.pluma\sessions\<课程代码>.json`。换课件就是另一条会话，**上下文不会串**；关掉再开还在；要重来点「清除本会话」。
- **默认范围是整门课**：不指定讲次时，9 讲一起检索，按分数取前 6 段；侧栏「讲次范围」可以限定到某一讲。
- **跨课件必须显式**：输入框左边的「引用其他课件」勾上，才会把别的课件纳入检索，回答里会标「已跨课件」。不勾就永远只在这一门里找。
- 参考答案里带来源：`[L05] §6 …`，跨讲/跨课件时一眼能看出出处。

## 它是怎么工作的（三步，都能单独跑）

| 步 | 在哪 | 干什么 |
|:--|:--|:--|
| ① 切段 | `engine/_ask.py` 的 `fragments()` | 把一讲切成「节 + 块」级片段：讲法、段落、引文、代码、例题、图注、表格 |
| ② 检索 | `search()` | 问题切成 2–4 字滑窗 + 英文词，按命中次数打分，标题命中额外加权；**每讲取前 3 段，合并后取前 6 段** |
| ③ 回答 | `build_prompt()` + `api_client.chat()` | 片段带 §节号、课件 p.N；系统提示要求「先给结论 + 每句标出处 + 没写就说没写」；最近 4 条问答作为上下文一起带上 |

## 三条命令

```powershell
# 看这一讲被切成几段（不花钱）
python engine\_ask.py L05 --dump

# 只检索：看命中哪几段、提问包多大（不花钱）
python engine\_ask.py L05 "生产者消费者两行 down 的顺序为什么不能反"

# 真问（会花钱，走你配的 key）
python engine\_ask.py L05 "…" --ask
```

界面走 `POST /api/ask`（多一个 `allow_cross` 开关与会话历史），与命令行共用同一套检索；
界面会多给一块「命中的片段（核对用）」，可以直接对照原文，判断它有没有编。

## 它不解决什么（先说清）

- **默认只在当前这门课里找**；跨课件必须显式勾选，且回答里会标出来——不勾就绝不搜别的课件。
- **找不到就会说「这讲里没写」**，但这靠提示词约束，脚本判不了它编没编——**得人看**。
- **不替代核对**：回答里的页码是片段自带的「课件 p.N」，仍要回原页确认。

## 花钱的边界

- 界面里点「提问」= 一次模型调用，进 `_logs\usage.jsonl` 台账，界面上「累计调用 / 估算花费」会跟着动。
- 没配 `sk-` 开头的钥匙时**不会扣费**：只显示命中的片段，并提示去设置里填。
