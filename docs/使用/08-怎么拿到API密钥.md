# 怎么拿到 API 密钥

> 一句话：**密钥不是羽毛笔发的，要去模型服务商那里自己申请。** 拿到一串 `sk-…` 开头的字符，粘进软件就完事。
>
> 不填也能用：只看成品 PDF、只导出、只阅读都不需要密钥。**需要密钥的只有三件事**——问课件、让模型整理笔记、让模型撰写新内容。

---

## 一、先弄清要不要花钱

| 你要做的事 | 需要密钥吗 | 大概花多少 |
|:--|:--|:--|
| 看别人做好的讲义、导出 PDF、阅读、收藏 | **不需要** | 0 |
| 让模型写新一讲的正文（读你的课件 → 写节） | 需要 | 一讲几毛钱量级，按服务商报价算 |
| 问课件（对着这一讲提问） | 需要 | 一次几分钱 |

羽毛笔不抽成、不代充、不经手你的钱——你自己在服务商那边充，软件只负责把你的密钥存到本机。

---

## 二、申请（以 DeepSeek 为例，约 3 分钟）

1. **打开官网**：浏览器进 `https://platform.deepseek.com`（这是模型服务商的控制台，不是羽毛笔的网站）。
2. **注册 / 登录**：手机号或邮箱都行。
3. **进「API keys」页**：左侧菜单里找 `API keys`（有的版本叫「接口密钥」「密钥管理」）。
4. **点「创建 API key」**：名字随便填，例如 `羽毛笔`，方便以后分辨是哪台设备在用。
5. **立刻复制**：密钥只在刚创建时完整显示一次，关掉就再也看不到（只能删了重建）。
   - 形如 `sk-3f9a1c…`，一长串，**中间不能有空格或换行**。
6. **充值**：同一控制台的「充值 / 余额」页。不充值直接调用会报余额不足（`402`）。

> 用别的服务商也行：只要它兼容 OpenAI 的接口格式（火山方舟、硅基流动、阿里百炼、月之暗面等都提供兼容接口），就把它的「接口地址」与「模型名称」一并填进设置页。

---

## 三、填进羽毛笔（两个入口，任选一个）

| 入口 | 位置 | 适合 |
|:--|:--|:--|
| 第一次用的向导 | 启动后第 2 步「API 钥匙」 | 刚开始用，一次填完 |
| 设置页 | 右上角头像 → 设置 → 「API 密钥（留空表示不修改）」 | 换密钥、换模型、换服务商 |

同一页还能改三项：

- **接口地址（base_url）**：DeepSeek 填 `https://api.deepseek.com`；别的兼容服务填它文档里的地址（一般以 `/v1` 结尾）。
- **模型**：DeepSeek 官方推荐 `deepseek-flash`（快、便宜）或 `deepseek-v4-pro`（长推导更稳）。
- **保存目录**：成品 PDF 复制到哪（留空就只留在软件目录的 `01_讲义`）。

填完点保存，右上角的灯会从「API 未配置（不影响出 PDF）」变成「API 可用」。

---

## 四、想确认能不能用

三种办法，从省事到彻底：

1. **看灯**：界面右上角显示「API 可用」就是通了。
2. **问一句**：随便问课件一个问题，能回话且带【§节号 课件 p.N】出处就是通了。
3. **命令行探活（不花钱）**：

```powershell
python api\client.py --check
```

返回会写明读的是哪一份配置、连的是哪个地址。

---

## 五、报错对照表

| 现象 | 原因 | 怎么办 |
|:--|:--|:--|
| `401 Unauthorized` / 未授权 | 密钥错、被删、或复制时带了空格/换行 | 回控制台重新复制，粘完检查首尾 |
| `402` / 余额不足 | 没充值或用完了 | 控制台充值；或换更便宜的模型 |
| `404` / 模型不存在 | 模型名写错，或该服务商没有这个模型 | 填服务商文档里的准确模型名 |
| 连不上 / 超时 | 网络、代理、或接口地址写错 | 先在浏览器打开接口地址看是否可达；公司网络可能要配代理 |
| 用了很快就报余额不足 | 一次生成的 token 较多（课件长） | 换 `deepseek-flash`；或把一次生成控制在两三讲 |

## 六、安全：密钥存在哪、会不会泄露

- **只存在本机**：`%USERPROFILE%\.pluma\api.json`（Windows 上是 `C:\Users\<你>\.pluma\api.json`）。
- **不进仓库、不进安装包**：公开发布的源码与 exe 里都没有你的密钥；仓库里只有「去哪读密钥」的代码。
- **不上传**：只有调用模型那一下会发给**你自己配置的那个服务商**，中间不经过羽毛笔的服务器（羽毛笔没有服务器）。
- **被别人拿到等于花你的钱**：截图、录屏、发给别人之前记得把密钥那一段遮掉；怀疑泄露就去控制台把它删了重建。

---

## 七、没有网也能用吗

能，只是少了「让模型写」这一层：

| 没网 / 没密钥时还能做 | 说明 |
|:--|:--|
| 导入课件、建讲次、阅读原件 | 纯本地 |
| 用已有数据重出 PDF（`python engine\_make.py`） | 纯本地 |
| 导出、合订本、做题笔记的 PDF | 纯本地 |
| 问课件、撰写新内容、模型整理笔记 | 需要密钥与网络 |
